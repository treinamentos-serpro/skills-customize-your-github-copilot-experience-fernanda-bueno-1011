
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras usando strings, loops e entrada de dados do usuário em Python. Os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas.

**Habilidades praticadas:** Manipulação de strings, loops, condicionais, seleção aleatória

## 📝 Tarefas

### 🛠️ Seleção Aleatória da Palavra

#### Descrição
Escolha aleatoriamente a palavra secreta a partir da lista predefinida de palavras e inicialize as variáveis que representam o estado do jogo.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Inicializar as letras já adivinhadas e o número de tentativas incorretas permitidas


### 🛠️ Loop Principal do Jogo

#### Descrição
Implemente o laço que recebe os palpites do jogador, atualiza o progresso e controla as tentativas restantes.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras do usuário
- Mostrar o progresso atual da palavra no formato `_ _ _`
- Rastrear tentativas incorretas restantes
- Encerrar o jogo quando a palavra for adivinhada ou as tentativas se esgotarem


### 🛠️ Mensagens de Vitória e Derrota

#### Descrição
Ao final da partida, informe ao jogador se ele venceu ou perdeu.

#### Requisitos
O programa concluído deve:

- Exibir uma mensagem de vitória quando a palavra for adivinhada
- Exibir uma mensagem de derrota quando as tentativas se esgotarem
